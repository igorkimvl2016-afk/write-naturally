# Живой текст — write-naturally

Скилл для Codex, который пишет и редактирует русский текст естественным языком.

Он убирает канцелярит, повторы и шаблонные обороты, сохраняет смысл, факты и авторскую манеру. Не придумывает личные истории и не обещает обход детекторов ИИ.

## Установка

Передайте ссылку на этот репозиторий своему Codex и попросите:

> Установи скилл write-naturally из этого репозитория для использования во всех моих проектах.

Для ручной установки скопируйте папку `write-naturally` в `~/.agents/skills/`. Если скилл не появился, перезапустите Codex.

## Использование

> Используй $write-naturally: перепиши этот текст простым, живым языком, сохрани смысл и факты. [Текст]

Можно указать адресата, формат и тон или приложить образец своего стиля.

## Состав

- `write-naturally/SKILL.md` — инструкции.
- `write-naturally/agents/openai.yaml` — название и подсказка для интерфейса.
